# 精简范围与重建规则

源码、SDK驱动源码、XCI/BD配置是复现输入；.xpr、IP输出HDL、对象库、ELF、比特流、XSA与IDE数据库均由工具生成，不作为本包预置内容。

默认产物写入build_out，独立于源码。不要把删除/清理规则应用到model/sd_parameters，它们是量化模型运行输入。上位机测试中的一个小型“演示回放_非实测.log”是测试夹具，不是实际分拣记录。

当前BSP源取自保存的Vitis平台，编译时补上原Vitis应用已有的旧寄存器名称兼容定义。没有依赖预编译libxil/libxilffs。新ELF的符号地址和加载哈希由构建脚本重新生成。

要导入Vitis IDE，在PowerShell运行安装目录下的xsct.bat，参数为scripts/create_vitis_workspace.tcl。该可选入口从新XSA生成工作区。
