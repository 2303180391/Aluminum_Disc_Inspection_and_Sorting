# 五舵机定位识别抓取分拣上位机 — ARM5 LOC1

本目录程序配套 E:\model\metal_defect_arm5_20261026\runtime 新固件。
原 E:\competition_best 未修改。不要用原四舵机上位机或原最佳工程的加载入口控制这一版。

2026-10-27 固定原点更新：使用用户指定 720p 参考图的左下内角为 O，X 向右、Y 向上，内框 100×100 mm。
不再要求白色原点可见，但仍要求实际黑色内框通过参考位姿校验；改变相机安装/镜像/观察方向后必须重新确认。
新模式和首次只定位步骤见 ../FIXED_ORIGIN_20261027.md；原先安装的旧 ELF 不会自动获得此修改。

## 先加载配套固件

本次只改 ARM 软件和电脑上位机，没有修改五路 PWM 的比特流、接线、模型权重、阈值、SD 参数或 BOOT.BIN。
但新增的 TEACH / LOCATE 指令和坐标状态需要新 ELF；原来已经运行的旧 ELF 不会自动更新。
仍通过 XSCT 加载，断电后不保证从 SD 自动启动这一候选版。

1. 先支撑机械臂、放下工件，关闭舵机外部电源（物理断开）。
2. 五路 PWM 和已确认的共地线可保持原接法，不要带电换线。
3. 开发板及 SD 卡保持正常，关闭旧上位机窗口，在 XSCT 执行：

```tcl
set arm5 {E:/model/metal_defect_arm5_20261026/runtime}
source $arm5/load_arm5_wired_poweroff.tcl
```

此脚本会系统复位、初始化 PS、下载配套 bit 和 ELF；仅可在舵机外部供电已断开时执行。
成功标志 ARM5_LOADED CPU0_RUNNING PWM_DISABLED，HDMI 应有正常画面。
加载不使能、不抓取、不自动记录观察位。失败时保留完整输出，不要盲目 con。
需要查看时可 source $arm5/arm5_status.tcl，此只读脚本不改变 CPU/PWM。

## 电脑连接

关闭旧上位机后，双击本目录“启动上位机.cmd”。
启动器会核对 MetalDefectMonitor.next.exe 的 SHA256 并替换主程序；不会强制关闭正在运行的旧窗口。

- USB 数据线连接开发板 PS_UART（J12），不是 PL_UART 或 USB_SLAVE。HDMI 独立显示视频。
- 选设备管理器中实际对应的 COM 口，不固定认为一定是 COM3。
- 115200 / 8N1 / 无流控，DTR 与 RTS 关闭。串口助手不能同时占用同一 COM。
- 点击连接只发送无动作 HELLO，既不使能，也不启动分拣。
- 新版要求配套 ARM5 STATE＋同一会话、同一 tick 的 LOCSTATE，才能开放机械臂按钮。
- 若显示旧固件或等待定位状态，请检查是否重新加载了本次 ELF、CPU 是否运行；仅重新下载 bit 不够。

## 首次使用顺序

1. 确认活动范围安全，接通舵机外部电源，点击“使能 / 初始姿态”。可能立即运动，等待回 HOME 并空闲。
2. 已确认 HOME 实际正常、相机完整看到 100×100 mm 黑色内框且方向与参考图一致后，点击“记录当前观察位”。固定模式不要求识别白贴。它只记录当前指令姿态，不移动机械臂，不是记录关节传感器反馈。
3. 在内框内放一枚圆片，点击“仅定位验证”。机械臂会先返回观察位、稳定 2 秒、采集并计算圆心，然后停在观察位；不靠近圆片、不下降、不夹取、不投放。
4. 查看整数毫米坐标 X / Y，多放几个点与实际方位和尺量对照。找不到内框、原点或圆片时坐标无效，不能把旧值当作新结果。
5. 只有坐标方向和队友九点机械标定、U/T 高度及四个篮子位置均确认后，才点击“定位→识别→分拣”。

完整单次流程：
返回观察位 → 稳定 2 秒 → 720p 内框和圆片定位 → 整数毫米坐标 →
按九点插值靠近圆片上方 U 平面 → 稳定 3 秒、五帧缺陷投票 →
下降 T 平面、夹取、抬起、按类别投放 → 回 HOME、停止等待下一次触发。

类别为 0 无缺陷 / 1 划痕 / 2 凹陷 / 3 脏污。
一次按钮只触发一轮，忙碌时不接受下一轮，也不排队。
原 PL_KEY1 保留为完整流程启动；不要与电脑同时操作。
重新加载硬件后观察位会丢失，须重新记录。坐标系以胶布内框为准，不是屏幕左上角像素原点。
U 是队友示教的接近位置，约高于抓取平面 30 mm，不等于相机距桌面 10 cm；不是自动恒高或避碰。

## 显示及保护

界面显示返回观察位、稳定定位、靠近、五帧分类、抓取投放和返回阶段；
显示本轮 X/Y 整数毫米、观察位/标定状态、票数及诊断错误。
新定位开始、定位失败、失能、断线、重启或重新记录观察位时，不将上次坐标作为本轮有效输出。
坐标不是闭环机械臂到位反馈，动作完成也不证明夹住或落篮成功。

CRC16、连接会话、单调序号和板端 2 秒状态凭据沿用原保护。
相同序号同一命令返回缓存结果，不重复执行；忙碌拒绝重复操作。
只允许一条待确认指令；确认超时不会重发，必须观察实物后重新握手读取现状。
STATE 超过 3 秒未更新会锁定按钮，LOCSTATE 不能单独延长状态有效期。
这些保护不是硬实时安全认证。

“机械臂失能”只在空闲、无待处理请求时开放；先支撑机械臂、放下工件。
失能关闭 PWM，不切断外部电源，可能下垂、松爪，**不是急停**。
断开串口/退出程序/电脑断线不会停止已开始的板端动作。
始终保留独立的舵机电源切断手段并防护下坠；运动中禁止下载、换线、复位。
“解除识别失败”不会自动重启；动作超时等故障须先本地检查。

## 日志、统计和编译

保留原日志、CSV、回放与演示。演示/回放不连接设备、所有机械臂控制锁定。
只对完整观察到的稳定→采样→已接受分类指令→动作→返回流程计数；
仅定位、HOME、中途连接、缺日志或失败不会计作分拣完成。
分类指令、动作开始和返回可能共享最后一个分类帧号，按不同有序事件判断，不要求伪造新推理帧。
本机统计不是开发板总产量，不是传感确认的抓取成功率。

logs/serial_时间.log 保存带电脑时间的 RX/TX，*_events.csv 保存动作记录。
清空本机统计不会覆盖历史日志。原复制保留日志不是本次 ARM5 实测记录。

build.ps1 使用 .NET Framework 4.x csc，先运行解析/控制测试，再编译程序。
-StageOnly 只生成暂存 EXE；使用启动器由用户显式替换。
docs/VALIDATION.md 记录本版离线验证范围。本次软件尚需用户实板验证握手、记录观察位、定位结果和完整流程。
